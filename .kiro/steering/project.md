# Project: Life Dashboard - Ziqlo

## Overview
A To-Do List Life Dashboard built for CodingCamp by Zikra Rachma Zeity.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Browser LocalStorage for persistence
- No frameworks or build tools required

## Project Structure
- `index.html` — main entry point
- `css/style.css` — all styles (warm-grey modern aesthetic, light/dark mode)
- `js/app.js` — all JavaScript logic

## Features
- Live clock, date, and time-based greeting
- Customisable user name and profile photo
- Focus timer with configurable Pomodoro duration
- To-do list with add, edit, complete, delete, sort, and duplicate prevention
- Quick links saved to LocalStorage

## Coding Standards
- Use only vanilla JavaScript — no frameworks
- Keep all styles in css/style.css, all logic in js/app.js
- Store all user data in localStorage with descriptive keys
- Write clean, readable, commented code
