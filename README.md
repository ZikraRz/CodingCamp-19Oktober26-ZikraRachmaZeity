# Life Dashboard — Trus Tamah

A modern, aesthetic To-Do List Life Dashboard built with HTML, CSS & Vanilla JavaScript.

## Features

| Feature | Details |
|---|---|
| Clock & Greeting | Live clock, date, and time-based greeting |
| Focus Timer | Configurable Pomodoro-style timer with progress bar |
| To-Do List | Add, edit, check-off, delete tasks — saved to LocalStorage |
| Quick Links | Add & remove favourite site shortcuts with favicons |

## All 5 Challenges Completed

- **Light / Dark Mode** — Toggle button (top-right), persists in LocalStorage, respects OS preference
- **Custom Name in Greeting** — Click "edit name" to personalise your dashboard
- **Change Pomodoro Time** — Set any duration (1–120 min) via the timer settings
- **Prevent Duplicate Tasks** — Alert shown when adding/editing to an existing task name
- **Sort Tasks** — Sort by Default, A to Z, Z to A, or Done Last
